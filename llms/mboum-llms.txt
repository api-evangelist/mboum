# Mboum

> Mboum is a REST/JSON stock and options market-data API. It provides real-time and
> historical quotes, options chains, unusual options activity, technical indicators,
> stock financials and fundamentals, analyst ratings and price targets, SEC filings,
> insider trades, institutional holdings, calendar events (earnings, dividends, IPOs,
> splits, economic events), market screeners, movers, news and crypto data. Data is
> licensed from multiple market-data providers and served from AWS.

Base URL: https://api.mboum.com
Authentication: API key (Personal Access Token) sent as `Authorization: Bearer {KEY}` header or `apikey` query parameter. All endpoints require an active subscription.
Rate limit: 15 requests/second (HTTP 429 on exhaustion); monthly request quota set by plan.
Versioning: path-based, /v1, /v2 and /v3 served in parallel.
